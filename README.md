# 学习项目 — Raft 风格生存游戏 / Learning Project — Raft-style Survival Game / 学習プロジェクト — Raft風サバイバルゲーム

这是我用于**学习和技能提升**的项目，仿照第一人称海上生存游戏《Raft》，**目前仍在持续更新中**。  
これは私の**学習とスキル向上**のためのプロジェクトで、一人称視点の海上サバイバルゲーム『Raft』を模倣したもので、**現在も継続的に更新中**です。  
This is a project for **learning and skill improvement**, inspired by the first-person ocean survival game *Raft*. The project is **still under continuous development**.
